# CitiSense Design Style Guide (for Figma)

Use these exact values in Figma to match the working app's "Premium" look.

## 🎨 Color Palette
| Element | Hex Code | Purpose |
| :--- | :--- | :--- |
| **Background** | `#0F172A` | Main app background (Dark Blue) |
| **Primary** | `#3B82F6` | Buttons, titles, and active states |
| **Accent** | `#10B981` | Positive sentiment, success messages |
| **Error** | `#EF4444` | Negative sentiment, delete buttons |
| **Warning** | `#F59E0B` | Neutral sentiment, pending status |
| **Text Primary** | `#F8FAFC` | Main headers and labels |
| **Text Secondary**| `#94A3B8` | Descriptions and placeholders |
| **Glass BG** | `rgba(255,255,255, 0.05)` | Card backgrounds (5% white opacity) |
| **Glass Border**| `rgba(255,255,255, 0.1)` | Card borders (10% white opacity) |

## 🖋️ Typography
*   **Font Family**: `Outfit` (Available on Google Fonts)
*   **Headings**: Semi-Bold (600), 24px - 32px
*   **Body Text**: Light (300) or Regular (400), 14px - 16px
*   **Buttons**: Bold (700), 16px

## 📐 Layout & Spacing
*   **Screen Padding**: 24px (left and right)
*   **Card Border Radius**: 24px
*   **Button Border Radius**: 16px
*   **Glassmorphism Effect**: Background Blur: 10px

## 📱 Interactive Elements
*   **Password Toggle**: Icon changes from `👁️` (Hidden) to `🙈` (Shown).
*   **Status Tags**: Rounded pills with 10% background opacity of the color (e.g., Negative has a light red background).
