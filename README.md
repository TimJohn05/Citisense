# CitiSense

**Urban feedback & resolution platform for Barangays of Calamba City, Laguna.**

Report community issues (waste, roads, water, lighting) with photos/videos & map location. Barangay officials review and resolve with proof photos. System admin gets full oversight with dashboards & logs.

## Tech Stack

- **Language:** Dart
- **Framework:** Flutter (Material 3)
- **Maps:** flutter_map + OpenStreetMap
- **Location:** geolocator
- **Camera:** image_picker + permission_handler
- **State:** provider (ChangeNotifier)
- **Charts:** fl_chart
- **Backend:** Firebase (Auth + Firestore + Storage)
- **Video:** Cloudinary (signed delivery URLs)
- **Font:** Public Sans
